## 1. Why Backlinks Matter

Google uses backlinks as "votes of confidence." Each quality link from another website to yours signals that your site is trustworthy and authoritative.

| Your current state | After backlink building |
|---|---|
| On-page SEO ✅ complete | Same, plus domain authority |
| No backlinks (new site) | 5–15 quality backlinks within 3 months |
| Ranks for name/brand | Ranks for competitive keywords too |
| Invisible to Google Maps | Visible on Google Maps (GBP backlink) |

**Expected timeline:**
- Weeks 1–2: Tier 1 links go live → Google discovers them
- Weeks 3–6: Search Console shows indexing improvement
- Months 2–3: Rankings improve for name/brand searches
- Months 3–6: Rankings improve for "Hatha Yoga Austria" (with consistent effort)

## 2. Backlink Quality Rules

Not all backlinks are equal. One link from a high-authority site (e.g., isha.sadhguru.org) is worth more than 50 links from random blogs.

### Quality Indicators (GOOD)

| Signal | Example | Why |
|---|---|---|
| Relevant niche | Yoga blog linking to yoga teacher | Topical relevance |
| High domain authority | Isha Yoga, Mindvalley, Google | Trusted source |
| Local relevance | Austrian wellness directory | Local SEO boost |
| Editorial link | Written as a recommendation | Natural, not paid |
| Contextual | Link inside an article, not a footer | More weight |

### Red Flags (AVOID)

| Signal | Example | Why |
|---|---|---|
| Paid links | "Buy 100 backlinks for $5" | Google penalty risk |
| Link farms | PBNs (Private Blog Networks) | Google can detect and penalize |
| Irrelevant sites | Casino site linking to yoga site | Zero value, possible harm |
| Reciprocal link schemes | "I link to you, you link to me" | Low value if excessive |
| Spammy directories | 500 free directory submissions | Low quality, wasted time |

**Rule of thumb:** If a human would genuinely recommend your site from that page, it's a good link. If it only exists for SEO, skip it.

### How to Track in Google Search Console

1. Open Search Console
2. Go to **"Links"** (left sidebar, scroll down)
3. You'll see:

4. Check this monthly to see new backlinks

## 9. Backlink Audit & Monitoring

### Monthly Backlink Audit (15 min/month)

1. Open Google Search Console → "Links"
2. Export the list of linking sites
3. Compare to last month — note new links
4. Check for any **lost links** (previously linking sites that no longer link)
5. If a high-value link was lost, reach out to the site owner

### Quarterly Deep Audit (1 hour/quarter)

1. Use Ahrefs Free Backlink Checker to get your top 100 links
2. Check each link is still live (visit the page)
3. Note any toxic/spammy links — disavow them in Search Console if needed
4. Identify which content attracted the most links — create more like it
5. Review competitor backlinks (search "Hatha Yoga Austria" → check who links to top results)

### Disavowing Toxic Links

If you ever get spammy/low-quality backlinks (e.g., from gambling/casino/pharma sites), you can tell Google to ignore them:

1. List the URLs in a `.txt` file (one per line)
2. Go to Google Search Console → **"Disavow links"**
3. Upload the file
4. Google will ignore those links when evaluating your site

**Only do this for genuinely toxic links. Don't disavow low-quality but legitimate links.**

## 10. What NOT to Do

| ❌ Don't | Why |
|---|---|
| Buy backlinks (Fiverr, etc.) | Google penalties, deindexing |
| Use PBNs (Private Blog Networks) | Google detects and penalizes |
| Exchange links excessively | Devalues the link signal |
| Submit to 500 free directories | Low quality, wasted time, possible penalty |
| Use automated link building tools | Creates spammy, detectable patterns |
| Spam blog comments with links | No value, possible penalty |
| Use exact-match anchor text excessively | Looks unnatural to Google |
| Pay for sponsored links without `rel="sponsored"` | Violates Google guidelines |

### What TO Do

| ✅ Do | Why |
|---|---|
| Build real relationships | Natural, high-quality links |
| Create valuable content | Others link to you organically |
| Get listed in relevant directories | Legitimate citations |
| Be patient | Backlink building takes months |
| Focus on quality over quantity | 1 good link > 50 bad links |
| Diversify anchor text | Natural link profiles use varied anchors |
| Track and monitor | Know what's working |
